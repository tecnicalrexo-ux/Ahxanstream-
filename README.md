# 🎬 Ahxanstream - Watch Your Favorite Content

Ahxanstream is a modern streaming platform where you can watch your favorite movies and series.

## Features

✨ **What We Offer:**
- 🎥 Browse Popular Movies
- 📺 Stream Latest Series
- ⭐ Rating System
- 🎯 Easy Navigation
- 📱 Responsive Design
- 🌙 Dark Mode UI

## Quick Start

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/tecnicalrexo-ux/Ahxanstream-.git
   cd Ahxanstream-
   ```

2. **Open in Browser:**
   - Simply open `index.html` in your web browser
   - Or use a local server:
   ```bash
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```
